


# Cмарт-квиз для сбора заявок на разработку дизайн-проекта помещения


### Реализованная функциональность


* Интерактивный многошаговый квиз для расчёта стоимости дизайн-проекта с адаптивными вопросами;
* Валидация и автоматическое форматирование контактных данных (имя, телефон, email, согласие на обработку);
* Асинхронная отправка email-уведомлений клиенту и менеджеру без блокировки основного потока;
* Административная панель для просмотра списка заявок, копирования телефонов и удаления записей;
* Сбор и передача UTM-меток для аналитики рекламных источников.



### В чём особенность проекта?



* Динамическая генерация вариантов ответов на основе предыдущих шагов (выбор типа помещения меняет список комнат);
* Клиент-серверная валидация данных через Pydantic-модели, гарантирующая строгий контроль типов на бэкенде;
* Неблокирующая фоновая отправка почты через `aiosmtplib` и `BackgroundTasks` FastAPI.



### Основной стек технологий:

* React, Vite, JavaScript (ES6+).
* HTML, CSS.
* Python 3.12+, FastAPI, Uvicorn.
* Pydantic, SQLAlchemy, aiosmtplib, python-dotenv.
* SQLite / PostgreSQL / MySQL.



### Демо

Фронтенд доступен локально по адресу: http://localhost:5173

Бэкенд и API-документация (Swagger UI): http://localhost:8000/docs

Реквизиты тестового пользователя: доступ к админ-панели открыт по маршруту /admin (без авторизации в демо-режиме)



### Среда запуска

* требуется установленный Node.js (версия 18+);
* требуется установленный интерпретатор Python (версия 3.12+);
* требуется установленный пакетный менеджер npm и pip;
* для работы уведомлений рекомендуется аккаунт Gmail с включённым доступом через App Password.



## Установка

### Бэкенд

#### Установка зависимостей бэкенда
```
cd Back
python -m venv .venv
source .venv/Scripts/activate  # Для Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```
#### Обязательно создать и заполнить файл .env
```
MAIL_BACK =  Почта для отправки писем
MAIL_BACK_PASS = Пароль для приложения
DATABASE_URL = Путь к БД. Например: 'postgresql://primer:12345@localhost:5432/db'
Запуск бэкенда
```
#### Для запуска бэкенда:
```
uvicorn main:app --reload
```
### Фронтенд

#### Установка зависимостей фронтенда
```
cd Front
npm install
npm install vite
```
#### Для запуска фронтенда:
```
npm run dev
```
